    Поэтажный план

    {% if plan %} {% comment %} The drawing and the contours are two pictures in one frame: both share a `viewBox` and an aspect ratio, so a contour falls exactly where the space is drawn. The frame is set by the ratio from the plan rather than by the file's dimensions: an export may declare neither width nor height. The drawing itself arrives as an image from the application's own address — scripts inside an SVG are not executed that way, and the file still travels through the chokepoint. The frame's size is limited by the window's height (`.floor-plan`): the plan is part of the floor screen, not the screen itself, and the tree on the left and the space card on the right must stay visible beside it. {% endcomment %}
    {% comment %} `data-contour` is the screen's contract, paired with `data-space` in the tree: it is by a space's code that the plan and the tree find each other. The fill is translucent so that the drawing reads through it. The colour arrives from the layer already computed (`plan_layer`) and is put straight on the contour rather than chosen here by class: the next layer — tenants' arrears, contract deadlines — will take this same place, and the markup will need nothing for it. `data-paint` names the variety by the same key as the legend entry does. A contour outside any layer — a stairwell, a shaft, a double-height opening — stays a single line without a fill: there must be no unexplained gaps on the drawing, but neither can they be passed off as a type of space. The layer gives them nothing, so their caption is a name and nothing more. A contour is selected by the same means as a tree node (`_space_select.html`): that is how the plan becomes something you can question by pointing at it. {% endcomment %}
    {% comment %} The legend: without it a colour has to be guessed, and a guess reads as a fact. It is assembled by the layer and only out of what is drawn on this floor — an entry for a colour absent from the drawing would be a caption to an empty space. Varieties with no fill at all get no entry. The layer is named: the plan shows one layer at a time, and the reader must know which. The switcher will stand here too, once there are more layers. {% endcomment %} {% if painting.legend %}
