{% comment %} A menu item: a section of the application, its label and its icon. Which section is open is not decided here — it arrives in `section`, and the item merely compares it with its own. It lives in a file of its own because there are three items now and there will be more: the highlighting, the classes and the `title` would otherwise be rewritten in each one, and an item that drifted apart would put out the highlight exactly where it was needed. Expects: `section` — the open section, `name` — this item's section, `url`, `label`, and `icon` — the outline of the icon. {% endcomment %} {# The label is hidden when the menu is collapsed, so the item's name is duplicated in `title`. #} {{ label }}
