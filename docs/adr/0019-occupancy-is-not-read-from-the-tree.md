# Занятость не выводится из дерева, и итога по зданию нет

Каждое помещение считает свои аренды само. Сдача помещения не сдаёт вложенные в него, и
сумма арендуемых площадей по этажу или по зданию не печатается нигде.

Связь в дереве означает одно из двух — помещение либо физически содержит вложенные, либо
только объединяет соседние в группу, — и по строке не видно, какая из двух перед вами.
Правило, выводящее занятость из иерархии, было бы верно для одного и молча неверно для
другого: сдача входного тамбура кабинеты за ним не сдаёт, а сдача уборной кабины в ней —
сдаёт. Выбрать одно поведение значит ошибаться в половине случаев, не зная, в какой.

На сегодняшних данных это 107 арендопригодных помещений из 324, стоящих внутри другого
арендопригодного, и 43 арендопригодных с арендопригодными детьми. Треть фонда.

Отсюда же запрет на итог. Сложить арендуемые площади по зданию значит посчитать эти 107
дважды — ровно та беда, из-за которой полка помещений не подводит итог по колонке площади
(ADR 0015). Довод дословно тот же: завышенное число, про которое неизвестно, насколько оно
завышено, хуже отсутствующего, потому что его процитируют.

## Последствия

- «Сдано 210 из 300 м²» говорится только про одно помещение и только на его карточке.
- Счёт свободного считается **в помещениях, а не в метрах**: «свободно 12 из 47
  арендопригодных» — величина, которую двойной счёт не портит, потому что помещение либо
  свободно, либо нет.
- Вопрос «сколько метров сдано в Manhattan» останется без ответа до тех пор, пока у
  помещения не появится признак «содержащее / объединяющее». Заводить его сейчас руками
  для 100 помещений — отдельный этап, и он не этот.
