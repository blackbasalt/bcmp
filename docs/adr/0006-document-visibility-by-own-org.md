# Документ виден по своей организации, а не по той сущности, к которой привязан

У поэтажного плана нет `org`: план виден там же, где виден его этаж, и второе место,
решающее чьи данные показывать, было бы способом однажды разойтись с первым
([ADR 0001](0001-orgmembership-for-tenant-scoping.md)). У документа сделано наоборот:
`org` обязателен, и `visible_to` фильтрует по нему.

Причина в том, что у документа целей привязки может быть несколько, а может не быть
ни одной. Документ, привязанный к Стороне, при наследовании видимости стал бы виден
всем, кому видна Сторона, — а Стороны заведены на всю систему, их 699 на одну
организацию, и заводились они как общий справочник контрагентов. Скан договора с
арендатором утёк бы между клиентами не по ошибке кода, а по правилу видимости.
Документ, не привязанный ни к чему, при наследовании не виден вообще никому и
пропадает из собственного раздела.

Это осознанное расхождение с прецедентом плана. Разработчик, который приведёт документы
«к единообразию» с `FloorPlan`, откроет утечку.

## Рассмотренные варианты

- **Наследовать видимость от цели привязки** — единообразно с планом и не требует
  нового поля. Отвергнуто по двум причинам выше: общая Сторона делает документ видимым
  чужим, а документ без привязки — невидимым своим.
- **Оставить `org` необязательным, как в схеме сейчас** — документ без организации не
  отфильтруется ничем и покажется всем. Это не смягчение правила, а его отсутствие.
- **Выводить `org` из привязки при сохранении** — тот же результат, что и наследование,
  но вычисленный один раз; ломается ровно там же, где и наследование, только молча.

## Последствия

- `Document.org` становится обязательным, и у `Document` появляется свой `visible_to` —
  второй такой чокпоинт в проекте после `Space`.
- Файл документа, близнец и его картинки раздаются представлениями через этот же
  чокпоинт. `MEDIA_URL` остаётся незаданным, как и для планов, чтобы прямую ссылку на
  файл нельзя было собрать в обход проверки.
- Один и тот же документ, нужный двум организациям, придётся загрузить дважды. Это
  принято сознательно: общий документ на два клиента — это вопрос, которого пока никто
  не задавал, и разделяемое владение стоило бы дороже дубля.
